# Super Agent 产品订阅与付费机制调研

> 调研时间：2026-04-17
> 调研目的：为 Loka Roundtable（每次消耗 ~10K-20K tokens）设计合理的付费机制
> 数据来源：各产品官方定价页、Finout 2026 定价分析、DemandSage 2026 报告

---

## 一、核心问题框架

本调研围绕三个核心问题展开分析：

1. **计费单位是什么？** — Credit（积分）、次数（Query Count）、还是纯功能解锁？
2. **订阅模式的底层逻辑是什么？** — 订阅费买的到底是什么？
3. **不同层级限制的到底是什么？** — 是限制用量、限制功能、还是两者都限制？

## 三、各产品底层计费逻辑深度分析

### 1. Perplexity AI — 「功能分区 × 次数限额」模型

**定位**：AI 搜索引擎 / Answer Engine

#### 计费单位是什么？

Perplexity **不使用 Credit/积分系统**。它的计费逻辑是：

> **订阅层级决定你能使用哪些功能，每个功能有独立的次数上限。**

具体来说，Perplexity 把产品拆成了 **4 个独立功能区**，每个功能区有自己的计量方式：

| 功能区 | 说明 | Free | Pro $20/月 | Max $200/月 |
|--------|------|------|-----------|-------------|
| **基础搜索（Quick Search）** | 快速问答，使用标准模型 | ✅ 无限 | ✅ 无限 | ✅ 无限 |
| **Pro 搜索（Pro Search）** | 使用高级模型（GPT-5.4/Claude 4.6/Gemini 3.1 Pro），更深度推理 | ~5 次/天 | ✅ 无限 | ✅ 无限 |
| **深度研究（Research / Deep Research）** | 多步推理，生成长篇研究报告 | ❌ | 20 次/天 | ✅ 无限 |
| **Labs（实验室功能）** | 生成仪表盘、表格、PPT、Web 应用 | ❌ | 50 次/月 | ✅ 无限 |

此外还有一些附加能力的次数限制：

| 附加能力 | Pro | Max |
|---------|-----|-----|
| 视频生成 | 3 次/月（无音频） | 增强版（15 次/月，含音频） |
| 文件上传 | 50 文件/空间，50MB/文件 | 更大配额 |
| 协作空间 | 最多 5 人 | 更大团队 |
| API Credits | $5/月 | 含 Perplexity Computer 10,000 credits/月 |
| Comet 浏览器 | ❌ | ✅ AI 原生浏览器 |

#### 订阅模式的底层逻辑

Perplexity 的订阅逻辑可以用一句话概括：

> **Free 用户只能用「基础搜索」；$20 买的是「Pro 搜索无限 + Research 和 Labs 的每日/月额度」；$200 买的是「一切无限 + 独占产品（Comet、Computer）」。**

本质上是一个 **功能解锁 + 次数配额** 的混合模型：
- **功能解锁**：Pro Search、Research、Labs、视频生成 — 只有付费才能用
- **次数配额**：即使付费了，Research 每天也只有 20 次（Pro 层），Labs 每月 50 次
- **无限解锁**：只有 Max $200/月 才能真正做到「无限」

关键洞察：**Perplexity 从不用 "Credit" 这个概念**。它把不同功能的使用次数分开管理，用户看到的是「今天还能做 18 次 Research」，而不是「还剩 500 积分」。这让用户非常清楚每个功能的用量，但不同功能的额度无法互相转换。

#### 不同层级限制的到底是什么？

| 限制维度 | Free → Pro 跳跃 | Pro → Max 跳跃 |
|---------|----------------|----------------|
| **功能解锁** | 解锁 Pro Search 无限、Research、Labs、视频生成、高级模型选择 | 解锁 Comet 浏览器、Perplexity Computer（自主 Agent） |
| **用量上限** | Pro Search 从 ~5次/天 → 无限；Research 从 0 → 20次/天 | Research 从 20次/天 → 无限；Labs 从 50次/月 → 无限 |
| **模型质量** | 标准模型 → GPT-5.4 / Claude 4.6 / Gemini 3.1 Pro 可选 | Pro 同款 → 额外优先获得 o3-pro、Claude Opus 4 等最新模型 |

#### 企业层级

| 层级 | 价格 | 核心差异 |
|------|------|---------|
| Enterprise Pro | $40/座/月 | Pro 全部功能 + 500 Research/天 + SSO/SCIM + 15,000 文件上传 + 审计日志 |
| Enterprise Max | $325/座/月 | 一切无限 + 最高模型访问 + 增强视频 + 组织级数据洞察 |

#### 定价策略小结

| 策略 | 说明 |
|------|------|
| 2026年2月放弃广告，全面订阅制 | 强调答案客观性，不受广告利益影响 |
| B2D 硬件合作拉新 | Samsung、Logitech、Motorola、Bell Mobility 等赠送 1 年 Pro |
| 教育/政府优惠 | 学生 $10/月（或首年免费）；政府 .gov 邮箱免费 1 年 Pro |
| Startup 项目 | 6 个月免费 Enterprise Pro + $5K API credits |
| 年付折扣 17% | Pro $200/年、Max $2,000/年 |

**对 Loka 的启示**：
> Perplexity 证明了「功能分区 × 次数限额」模型的可行性。关键学习：
> 1. **不用 Credit，而是按功能类型独立计数** — 用户理解成本极低
> 2. **$20 是 AI 产品的心理锚点**，$200 是 power user 的天花板
> 3. **Free 用户也能用基础搜索无限次** — 低门槛拉新，但高级功能有硬上限
> 4. **Max 层级不只是「更多次数」，而是「独占产品」**（Comet、Computer）— 功能差异化 > 数量差异化

### 2. AskSurf.ai — 「双轨计费」模型（用户 = 次数，开发者 = 积分）

**定位**：Crypto/Web3 领域 AI 深度研究 Agent

#### 计费单位是什么？

AskSurf 的核心创新是 **两条产品线使用完全不同的计费单位**：

| 产品线 | 面向对象 | 计费单位 | 逻辑 |
|--------|---------|---------|------|
| **Ask + Deep Research** | 终端用户 | **次数（Query Count）** | 每次提问 = 1 次，每次深度研究 = 1 次 |
| **Surf Studio + API** | 开发者 | **积分（Credits）** | 每次 API 数据调用消耗不同积分 |

> 两套体系**完全独立**，互不混用。你的 Research 次数用完了，不能拿 Studio 积分来换。

#### 「次数」具体怎么计算？

对终端用户来说，计费非常简单：
- **即时问答（Instant）**：发一个问题 = 消耗 1 次即时问答额度
- **深度研究（Deep Research）**：发起一次研究 = 消耗 1 次深度研究额度
- Auto Mode 下系统自动判断路由到哪个，如果触发了 Deep Research 就扣 Research 额度

**不按 token 计费、不按回复长度计费、不按对话轮数计费。** 一次就是一次，不管回复多长。

#### 「积分（Credits）」具体怎么消耗？

Credits 只用于 Surf Studio / API：
- 每次通过 Studio 或 API 调用数据接口消耗不同 Credits（价格因接口类型而异）
- 覆盖数据域：市场价格、交易所订单簿、钱包余额、社交情绪、链上交易等
- CLI 工具免登录可获得 30 免费 Credits/天

#### 定价结构（当前实际价格，2026 年 4 月）

> 注：AskSurf 定价页当前只显示 **3 个层级**（Free / Pro / Max），此前的 Plus $9/月层级已不在定价页上。

| 层级 | 价格（年付） | 月付估算 | 即时问答 | 深度研究 | Surf Studio 积分 |
|------|------------|---------|---------|---------|-----------------|
| **Free** | $0 | $0 | 有限额度 | 1次/日，2次/周 | — |
| **Pro** | $39/月（年付） | ~$47/月 | ✅ 无限 | 100次/两周 | 500 一次性积分 |
| **Max** | $333/月（年付） | ~$401/月 | ✅ 无限 | ✅ 无限 | 12,000/月 + 首3月额外1,800 + 1,000 API Credits |

- 年付折扣：**17%**
- 支持加密货币支付
- 年付送 NFT（Pro → Surf Elite NFT，Max → Surf Genesis NFT）

#### 订阅模式的底层逻辑

AskSurf 的订阅逻辑：

> **Free 用户体验产品；Pro 买的是「无限即时问答 + 足量深度研究次数」；Max 买的是「一切无限 + Studio 开发者平台的完整访问权」。**

- **Free → Pro**：核心价值是「即时问答从有限变无限 + 深度研究从 1次/天变成 100次/两周」
- **Pro → Max**：核心价值是「深度研究变无限 + 开通 Surf Studio 完整数据平台」

#### 不同层级限制的到底是什么？

| 限制维度 | Free | Pro | Max |
|---------|------|-----|-----|
| **即时问答次数** | 有限 | ✅ 无限 | ✅ 无限 |
| **深度研究次数** | 1次/日，2次/周 | 100次/两周 | ✅ 无限 |
| **Surf Studio 访问** | ❌ | 仅 500 一次性积分（体验） | ✅ 完整访问（12K 积分/月） |
| **NFT 权益** | ❌ | 年付送 Surf Elite | 年付送 Surf Genesis |
| **优先级** | 标准 | 标准 | 高流量优先接入 + VIP 支持 |
| **新功能体验** | ❌ | ❌ | ✅ 优先体验 |

关键洞察：
- **对用户来说，限制的核心是「深度研究次数」** — 即时问答在 Pro 和 Max 都是无限的，所以付费的真正驱动力是 Research 的次数
- **Pro → Max 的价格跳跃巨大（$39 → $333）**，因为 Max 加入了一整条新产品线（Studio）

**对 Loka 的启示**：
> 1. **「次数」是面向用户最好的计费单位** — 一次 Research 就是一次，不管消耗多少 token
> 2. **双轨计费清晰隔离了用户和开发者** — Loka 未来如果有 API 开发者层，可以参考
> 3. **高价 Max 层要有「新产品线」支撑**，不能只是「更多次数」
> 4. AskSurf 没有中间档 — $39 直接跳到 $333，说明 Crypto 用户要么轻度使用，要么重度使用，中间需求不大

### 3. Manus — 「积分（Credit）」纯量化模型

**定位**：通用 AI Agent，能建网站、做幻灯片、深度研究（已被 Meta 以 $2B 收购）

#### 计费单位是什么？

Manus 是这四个产品中 **唯一使用纯 Credit 积分制** 的：

> **所有功能统一使用「Credit」作为计量单位。** 不同任务消耗不同数量的 Credit，用完即止。

这意味着：
- 建一个网站可能消耗 200 积分
- 做一次深度研究可能消耗 50 积分
- 生成一份幻灯片可能消耗 100 积分
- 所有功能共享同一个积分池

#### 「积分」的双池设计

Manus 的创新在于将积分拆成了 **两个池子**：

| 池子类型 | 说明 | 容量 | 刷新规则 |
|---------|------|------|---------|
| **每日刷新积分** | 每天自动补充，用不完当天作废 | 300/天（所有层级相同） | 每日 0 点刷新，不累积 |
| **月度积分池** | 每月固定额度，用完需等下月 | 4,000 / 8,000 / 40,000（按层级） | 每月刷新，不累积 |

用户使用任何功能时，**优先消耗每日刷新积分，用完后再消耗月度积分**。

这个设计的巧妙之处：
1. **每日 300 积分** = 保证用户每天都有理由打开产品（提高 DAU）
2. **月度积分池** = 控制重度用户的总消耗（控制成本）
3. **两池不可互换** = 日积分当天不用就没了，制造「不用就亏」的感觉

#### 定价结构

> 注：Manus 定价页使用 CSS 动画显示价格，无法直接抓取精确金额。以下价格基于此前公开信息，可能有偏差。

| 层级 | 价格（推测） | 每日刷新积分 | 月度积分 | 并发/定时任务 |
|------|------------|-----------|---------|-------------|
| **基础层** | ~$39/月 | 300/天 | 4,000 | 20 / 20 |
| **中间层** | ~$99/月 | 300/天 | 8,000 | 20 / 20 |
| **高级层** | ~$199/月 | 300/天 | 40,000 | 20 / 20 |
| **团队/企业** | 定制 | 定制 | 定制 | 定制 |

- 年付折扣 17%
- 新用户注册：1,300 免费积分 + 7 天免费试用

#### 订阅模式的底层逻辑

> **所有层级的功能完全相同。** 你付更多钱，买到的不是新功能，而是更大的月度积分池。

这与 Perplexity 和 AskSurf 有本质区别：
- Perplexity：高层级 = 新功能（Comet、Computer）+ 更多次数
- AskSurf：高层级 = 新产品线（Studio）+ 更多次数
- **Manus：高层级 = 纯粹更多积分，功能完全一样**

#### 不同层级限制的到底是什么？

| 限制维度 | 基础层 | 中间层 | 高级层 |
|---------|-------|-------|-------|
| **功能访问** | ✅ 全部 | ✅ 全部 | ✅ 全部 |
| **每日刷新积分** | 300 | 300 | 300 |
| **月度积分** | 4,000 | 8,000 | 40,000 |
| **并发任务** | 20 | 20 | 20 |
| **定时任务** | 20 | 20 | 20 |

> **Manus 限制的只有一样东西：月度积分池的大小。** 没有功能差异、没有模型差异、没有优先级差异。

这种模式的优缺点：
- ✅ 极其简单 — 用户只需要理解一个数字（还剩多少积分）
- ✅ 成本可控 — 每个用户的最大消耗是确定的
- ❌ 积分焦虑 — 用户不知道「一次研究到底要花多少积分」，导致不敢用
- ❌ 缺乏升级动力 — 如果功能一样，用户可能觉得「基础层就够了」

**对 Loka 的启示**：
> 1. **双池设计（日刷新 + 月度池）是 Agent 类产品的经典模式** — 值得考虑
> 2. **纯积分制的风险是「积分焦虑」** — 用户不知道一次操作要花多少积分
> 3. **如果用积分制，层级间最好有功能差异**，不然高层级吸引力不够
> 4. Manus 的「300/天」设计很聪明 — 保证了免费/低付费用户每天也能用，提高留存

### 4. GenSpark — 「积分 + 模型分级消耗」模型

**定位**：All-in-One AI Workspace + Super Agent 平台（11 个月达到 $200M ARR）

#### 计费单位是什么？

GenSpark 使用 **积分（Credits）** 作为核心计量，但加入了一个重要机制：

> **使用不同质量的模型，消耗不同数量的积分。**

这就是 GenSpark 的 **Ultra Mode**：
- **普通模式**：使用标准模型，消耗较少积分
- **Ultra Mode**：使用顶级模型（如 Claude Opus 4.7），消耗更多积分

同样一个问题，Ultra Mode 可能消耗 3-5 倍的积分。用户自己选择质量 vs 用量的平衡。

#### 定价结构

> 注：GenSpark 定价页需要登录才能查看，以下基于公开信息。

| 层级 | 价格 | 积分 | Ultra Mode | AI 工具访问 |
|------|------|------|-----------|-----------|
| **Free** | $0 | 有限每日积分 | ❌ | 基础搜索、基础 Chat |
| **Plus** | $19.99/月（年付约 $15.99/月） | 更多积分 | ✅ 消耗更多积分 | 全套（Slides、Docs、Designer、Video、Music、Meeting Bot、Claw） |
| **Business** | 企业定制 | 定制 | ✅ | 全套 + 团队管理 + 专属 Cloud Computer |

- 年付折扣 **20%**（高于行业平均 15-17%）
- 使用 Stripe 支付

#### 订阅模式的底层逻辑

> **Free 用户有有限积分和基础功能；Plus 买的是「更多积分 + Ultra Mode + 全套 AI 工具解锁」。**

GenSpark 的订阅同时包含两种限制：
1. **功能解锁**：Ultra Mode、AI Slides/Docs/Video/Music 等只有 Plus 才能用
2. **用量控制**：即使是 Plus 用户，积分用完也需要等下月刷新

#### 不同层级限制的到底是什么？

| 限制维度 | Free | Plus |
|---------|------|------|
| **积分额度** | 有限每日积分 | 更多月度积分 |
| **模型质量** | 标准模型 | 标准 + Ultra Mode（顶级模型） |
| **AI 工具** | 基础搜索和 Chat | 全套 AI 工具矩阵 |
| **Genspark Claw** | 基础 | 增强功能 |
| **新功能** | 标准 | 优先体验 |

关键洞察：**GenSpark 的 Ultra Mode 是一种「积分消耗加速器」。** 它不限制你用 Ultra Mode 的次数，但每次 Ultra 消耗更多积分，所以你的月度积分会更快用完。这巧妙地把「模型质量」和「用量」绑定在一起——想用好模型？那你的总使用量就得少一些。

**对 Loka 的启示**：
> 1. **Ultra Mode 的「分级消耗」思路**适合 Loka — Roundtable 用大模型消耗更多次数/积分，用 mini 模型消耗更少
> 2. **$20 再次被验证为 AI 订阅标准锚点**
> 3. **全栈产品矩阵**是 Plus 的核心吸引力 — 不只是「更多积分」，而是「解锁一整套工具」
> 4. GenSpark 只有 Free + Plus 两个个人层级（无 Max），说明可以先简单后复杂

## 四、计费模型横向对比

### 4.1 计费单位对比

| 产品 | 面向用户的计费单位 | 面向开发者的计费单位 | 用户是否需要理解 token？ |
|------|-----------------|-------------------|---------------------|
| **Perplexity** | 次数（按功能分类独立计数） | Token（API 按 token 计费） | ❌ 完全不需要 |
| **AskSurf** | 次数（即时问答 + 深度研究分开计数） | 积分（Studio Credits） | ❌ 完全不需要 |
| **Manus** | 积分（所有功能共享一个积分池） | 同上 | ❌ 不需要，但需要理解积分 |
| **GenSpark** | 积分（Ultra Mode 消耗更多） | 同上 | ❌ 不需要，但需要理解积分 |

**结论**：没有一个产品让终端用户直接面对 token。都做了一层抽象。

### 4.2 订阅买的是什么？

| 产品 | 买功能？ | 买用量？ | 买模型质量？ | 买独占产品？ |
|------|---------|---------|-----------|-----------|
| **Perplexity** | ✅ Research、Labs、视频 | ✅ 每个功能独立次数限额 | ✅ Pro 解锁高级模型，Max 解锁前沿模型 | ✅ Max 独占 Comet、Computer |
| **AskSurf** | ✅ 无限即时问答、Studio | ✅ 深度研究次数 | ❌ 所有付费层级模型相同 | ✅ Max 独占 Studio 完整访问 |
| **Manus** | ❌ 所有功能对所有层级开放 | ✅ 月度积分池大小 | ❌ 所有层级模型相同 | ❌ |
| **GenSpark** | ✅ AI 工具矩阵、Ultra Mode | ✅ 积分额度 | ✅ Ultra Mode 解锁顶级模型 | ❌ |

### 4.3 层级间的核心差异策略

| 策略 | 产品 | 说明 |
|------|------|------|
| **纯数量差异** | Manus | 高层级 = 更多积分，功能完全相同 |
| **功能 + 数量差异** | Perplexity, GenSpark | 高层级 = 新功能 + 更多用量 |
| **产品线差异** | AskSurf, Perplexity Max | 高层级 = 解锁整条新产品线 |

## 五、三种核心付费模式总结

### 模式 A：功能分区 × 次数限额（Perplexity）

```
用户看到的：「Pro Search 无限 | Research 还剩 18 次今天 | Labs 还剩 45 次本月」
```

- **优点**：用户对每个功能的剩余用量一目了然；不同功能的限额独立管理
- **缺点**：管理复杂度高（需要维护多个计数器）；用户可能不知道该用哪个功能
- **适合**：功能类型差异大、成本差异大的产品

### 模式 B：统一积分池（Manus / GenSpark）

```
用户看到的：「今日积分 280/300 | 月度积分 3,200/4,000」
```

- **优点**：统一计量，一个数字管全部；灵活——用户自己决定积分花在哪个功能上
- **缺点**：积分焦虑；用户不知道「一次操作花多少积分」；需要公示积分消耗表
- **适合**：功能多样、用户使用模式差异大的 Agent 类产品

### 模式 C：双轨分离（AskSurf）

```
用户侧：「Deep Research 还剩 92 次」
开发者侧：「Studio Credits 还剩 11,200」
```

- **优点**：消费者和开发者各得其所；用户侧极简，开发者侧精细
- **缺点**：两套体系增加产品复杂度；只适合同时服务两类人群的产品
- **适合**：同时面向终端用户和开发者的平台型产品

## 六、Loka 建议方案

### 产品功能

Loka 面向用户呈现两个分析模式（日常闲聊不计数，由 Agent 路由透明处理）：

| 功能 | 说明 | 成本 |
|------|------|------|
| **Fast 分析** | 单 Agent 投资分析（股票分析、行情解读等） | **~$0.05-0.10/次** |
| **Multi-Agent 分析（Roundtable）** | 多 Agent 共识讨论，深度投研报告 | **~$0.50/次**（~5K-10K tokens） |

> 日常对话（打招呼、简单问题）走轻量路由，不消耗次数，对用户无限制。
> 当 Agent 路由判断问题需要投资分析时，自动计入 Fast 分析次数。

### 成本估算

- Fast 分析：单 Agent 调用，**~$0.05-0.10/次**
- Multi-Agent 分析（Roundtable）：多 Agent 并行，**~$0.50/次**（~5K-10K tokens）

### 推荐方案：纯次数制

不做功能解锁，不做积分制。**两个模式分别有独立的次数限额。**

| 层级 | 价格 | 日常对话 | Fast 分析 | Multi-Agent 分析 |
|------|------|---------|----------|----------------|
| **Free** | $0 | ✅ 无限 | 10 次/周（≈40次/月） | 2 次/周（≈8次/月） |
| **Pro** | $29/月 | ✅ 无限 | 200 次/月 | 50 次/月 |
| **Max** | $79/月 | ✅ 无限 | 500 次/月 | 150 次/月 |

> **超额处理**：到达上限后提示升级，MVP 阶段不做按次付费。

### 经济模型

| 层级 | 月费 | Fast 成本（按$0.08/次） | Roundtable 成本（按$0.50/次） | 总成本上限 | 毛利（用满） | 毛利率 |
|------|------|----------------------|---------------------------|----------|-------------|-------|
| **Free** | $0 | $3.2（40次） | $4（8次） | $7.2 | -$7.2（获客成本） | — |
| **Pro** | $29 | $16（200次） | $25（50次） | $41 | -$12 | — |
| **Max** | $79 | $40（500次） | $75（150次） | $115 | -$36 | — |

> ⚠️ **如果用户用满全部额度，所有层级都亏损。** 但这是行业常态：
> - 行业经验：付费用户平均只用 **30-40%** 额度
> - Pro 用户用 35% 额度：Fast 70次($5.6) + Roundtable 18次($9) = $14.6 成本，**毛利 $14.4（50%）**
> - Max 用户用 35% 额度：Fast 175次($14) + Roundtable 53次($26.5) = $40.5 成本，**毛利 $38.5（49%）**
> - 需要持续监控实际使用率，必要时调整额度

### 定价要点

1. **纯次数制，两个模式独立计数**
   - 日常对话无限，Fast 分析和 Multi-Agent 分析分别有独立额度
   - 用户看到的是「Fast 分析还剩 X 次」「Multi-Agent 还剩 Y 次」

2. **定价依赖实际使用率**
   - 用满会亏损，但行业数据显示付费用户平均只用 30-40% 额度
   - Pro/Max 在 35% 使用率下毛利约 50%
   - 参考锚点：Perplexity Pro $20、AskSurf Pro $39

3. **Free 层控制获客成本**
   - Fast 10次/周 + Roundtable 2次/周，成本上限 ~$7/用户/月
   - 足够让用户体验两种分析模式，驱动付费转化

4. **年付折扣 17%**
   - Pro $289/年（≈$24.08/月）、Max $787/年（≈$65.58/月）

5. **考虑 AIUSD 支付**
   - 打通代币经济，Crypto 用户天然接受

### 后续迭代方向

| 优先级 | 方向 | 说明 |
|--------|------|------|
| v2 | 超额按次购买 | 到达上限后可按 $1/次 购买额外 Roundtable |
| v2 | 降低单次成本 | 优化 Agent 调用链、缓存策略，降低 $0.50/次的基准成本 |
| v3 | AIUSD Staking 获取会员 | 质押代币获得 Pro 权益 |
| v3 | NFT 会员权益 | 参考 AskSurf |
