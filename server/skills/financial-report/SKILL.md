# A 股财报数据分析

## 何时使用

当用户问到以下场景时调用 `financial_report` 工具（搭配 `stock_analysis` 和 `web_research`）：

- "X 业绩怎么样" / "X 营收 / 净利润多少"
- "X 业绩预告" / "X 一季报 / 中报 / 三季报 / 年报"
- "X 同比增长多少" / "X 扣非净利润"
- "X 财务摘要" / "X 现金流"
- "X 暴雷了吗" / "X 业绩变脸" / "X 商誉减值"
- "X 一季度业绩超预期吗" / "X 业绩 vs 预期"

## 工具返回的四个数据块

### 1. 同花顺财务摘要 (`abstract`) — 时间序列，最重要

每一行是一个报告期（季报/中报/年报），最近 12 期：

| 字段（中文） | 含义 |
|------|------|
| 报告期 | 2026-03-31 / 2025-12-31 ... |
| 营业总收入 | 营收（元） |
| 净利润 | 归母净利润 |
| 扣非净利润 | 剔除一次性损益后 |
| 营业总收入同比增长率 | YoY 营收增速 |
| 净利润同比增长率 | YoY 净利润增速 |
| 毛利率 | (营收-成本)/营收 |
| 净利率 | 净利润/营收 |
| ROE / ROA | 净资产/总资产收益率 |
| 资产负债率 | 杠杆水平 |
| 经营活动现金流净额 | 利润含金量验证 |
| 每股收益(EPS) | 每股盈利 |

**使用要点：**
- 看趋势比看单期数值更有价值（连续 4 季度同比下滑 = 周期性下行）
- 净利润同比与营业收入同比的差值：> 10pp 大幅扩张 = 经营杠杆兑现；< -10pp 收缩 = 成本压力
- 扣非净利润 vs 净利润：差值大 = 一次性损益拉高（如政府补贴 / 资产处置），盈利质量打折
- 经营现金流 / 净利润：< 1.0 = 利润含金量低（应收账款堆积或盈余管理）

### 2. 业绩预告 (`yjyg`) — 财报正式发布前的"剧透"

A 股规定：净利润同比变动 ±50% / 扭亏为盈 / 由盈转亏 等情形需提前发布业绩预告。**预告发布日 ≠ 正式财报日**，预告通常早 1-3 个月。

| 关键字段 | 解读 |
|------|------|
| 预测指标 / 预告类型 | 预增 / 预减 / 续盈 / 续亏 / 首亏 / 扭亏 |
| 预测数值（上下限） | 预告区间 |
| 同比增减 | 与去年同期比 |
| 公告日期 | 预告披露日 |

**信号价值：**
- "首亏" / "预减 50% 以上" = 重大利空，往往伴随股价大幅下跌
- "预增 100% 以上" / "扭亏" = 重大利好，但需验证基期效应
- 预告区间太宽（如 100%–300%）= 公司自己也没数，确定性低

### 3. 业绩快报 (`yjkb`) — 正式财报前的精确版

业绩快报披露具体营收 / 净利润数字（比预告精确），但**未经审计**。一般在正式年报前 1 个月内发布。

### 4. 业绩报表 (`yjbb`) — 正式公告

经审计的官方季报 / 年报，是最权威的版本。

## 分析框架

### 财报四问

1. **趋势是否健康？** — 用 abstract 看连续 4-8 期的营收、净利润、扣非净利润 YoY 走势
2. **盈利质量如何？** — 看扣非比例、毛利率走向、经营现金流 vs 净利润
3. **杠杆是否安全？** — 看资产负债率、ROE 拆解（杜邦分析：净利率 × 资产周转 × 杠杆）
4. **是否超预期？** — yjyg/yjkb 数字 vs 卖方一致预期；如果工具没给一致预期，则 vs 上一期 / 去年同期

### A 股财报日历（牢记）

| 时点 | 事件 | 策略动作 |
|------|------|----------|
| 1 月中下旬 | 年报业绩预告披露窗口（净利润同比 ±50% 必须披露） | 抢预期差 |
| 2 月底 | 业绩快报披露集中期 | 精确版数字落地 |
| 3-4 月 | 年报正式发布 | SUE 计算、PEAD 建仓 |
| **4 月 30 日** | 年报截止日（**未披露 = 利空**） | 警惕"披而未公"标的 |
| 7 月中旬 | 中报业绩预告 | 半年度预期修正 |
| **8 月 31 日** | 中报截止日 | 同上 |
| **10 月 31 日** | 三季报截止日 | Q3 数据验证全年预期 |

### 输出格式建议

当工具返回后，按以下结构组织答复（中文用户）：

```
## 业绩概况

营收 X 亿元（YoY +X%）／归母净利润 Y 亿元（YoY +X%）／扣非 Z 亿元（YoY +X%）
[一句话定调：超预期 / 符合预期 / 不及预期 / 暴雷]

## 盈利质量

- 毛利率 X% （[较上期变化]）
- 净利率 X%
- 扣非比例 X%（[high/normal/low]）
- 经营现金流 / 净利润 = X.X（[high/normal/低含金量]）

## 趋势与拐点

[最近 4-8 期 abstract 数据画图叙事，识别拐点]

## 关键风险

- 应收账款 / 存货 异常增长？
- 资产负债率突变？
- 商誉减值风险？
```

## 与其他工具的搭配

- 用户问"X 业绩超预期吗" → `financial_report` + `web_research`（拉卖方一致预期 / 分析师报告）
- 用户问"X 该不该买" → `stock_analysis`（价 + 技术面）+ `financial_report`（财报）+ `web_research`（消息面）
- 用户问"X 业绩公布后股价会怎么走" → `financial_report` + `stock_analysis`（看历史 PEAD 反应）+ `web_research`

## 注意事项

- akshare 数据来源是东方财富 / 同花顺**网页**，访问频率过高会被反爬封禁 — 已在底层加了重试
- 业绩预告区间数值（净利润预增 50%-100%）需取中位数做点估计，并标注"预告区间"
- 一次性损益要单独识别：处置子公司股权、政府补贴、税收返还、投资收益（公允价值变动）— 扣非净利润才反映主业盈利
- 小市值股票（< 100 亿）财报可信度需打折，财务造假概率高
- 港股、美股 ticker 调本工具会返回拒绝错误 — 改用 `stock_analysis` 或 `sec_filings`
- 本框架仅用于研究分析，不构成投资建议
